
**StudyBuddy**

StudyBuddy combines flashcards, daily habits, and a Pomodoro timer in one self-contained HTML workspace. A persistent sidebar switches between the three tools without interrupting your current study session.

**Getting started**

Download `StudyBuddy.html` and open it in a modern browser. No installation, account, or server is required. Keep using the same browser and file location for consistent access to saved data.

**Flashcards**

Create named decks and enter one card per line using `front::back`. Both sides support Markdown and mathematical notation. Edit cards, rename decks, or delete either as needed. Study reviews due cards using spaced repetition, while Cram practices every card without changing its review schedule.

**Habits**

Add daily habits, mark them complete, and track consecutive day streaks. Undo today's completion when necessary. Habits can also be renamed or deleted.

**Focus**

Set work duration, break duration, and cycle count. Start, pause, resume, or reset your session. The timer continues when you switch tools. Choose an image or GIF background, use a direct image URL, restore the default image, or switch to a plain background. Ambient recordings include rain, fireplace, river, thunderstorm, crickets, and birds. An optional Spotify player accepts supported Spotify links.

**Slot**

Optimize your schedule by inputting your fixed time commitments, your tasks, and priorities. 

**Keyboard shortcuts**

Use `Alt+1`, `Alt+2`, and `Alt+3` to switch tools. During flashcard review, press Space to reveal an answer, then use Left or Right Arrow to grade it.

**Saving and backups**

Cards and habits save in your browser. Export JSON backups regularly, especially before moving devices, clearing browser storage, or importing data. Each tool imports and exports its own compatible backup format. Importing replaces that tool's current data.

**Offline use**

The core tools, fonts, Markdown renderer, and math support are embedded. Spotify, streamed ambient sounds, and remote background URLs require internet. Timer settings, custom backgrounds, and music selections last for the current page session and reset after reloading.
